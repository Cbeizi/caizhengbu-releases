# 财政部更新源

此仓库只分发财政部 iPhone 安装包、更新清单和说明，不含应用源码、个人账本、付款截图或诊断日志。

在两台 iPhone 上分别打开 SideStore → Sources（来源）→ 添加来源，粘贴：

```
https://pub-4b274449c705402b9aa4f4033e0865a9.r2.dev/source.json
```

添加后在 SideStore 中更新财政部。安装带更新入口的版本后，也可从财政部“设置 → 应用更新”发起更新。

签名和安装由 SideStore 完成，沿用原来的签名账户并保留现有 App 升级。SideStore 的续签要求继续适用。

安装包和 SHA-256 校验值见 [Releases](https://github.com/Cbeizi/caizhengbu-releases/releases)。最低系统要求以更新清单为准。
